A simple start.

Install on your main Mac

RetinaLink Host will be installed in Applications. If Host is already open, quit it before continuing. Keep one installed copy of Host; an older copy in your home Applications folder is not replaced by this installer.

Your iMac needs Viewer once

Open Host and choose Save Viewer Installer… to transfer the signed Viewer app to your iMac, or use the separate Viewer download. Open Viewer on the iMac, then choose Add Display in Host. Compare the verification number on both Macs and approve only the pairing you started.

Your Mac stays in your control

Normal pairing does not need Remote Login or an iMac password. macOS will ask you to allow Screen Recording for Host and Local Network access if required.

Encryption stays unchanged

This installer does not change FileVault, accounts, automatic login, sleep or screen-lock settings. On a FileVault-protected Intel iMac, someone must unlock its startup disk after a restart before Viewer can run.

Already paired? Installing the same developer’s signed update preserves saved trust. Host controls signed automatic updates for both Macs. With version 0.8.3 or later on both ends, only Host needs internet; Viewer receives updates through the paired display connection. Viewer 0.8.2 or earlier needs one upgrade first, using its own internet connection or a signed replacement in its existing location. Native 5K at 60 fps is a target; actual performance depends on your Macs, network and workload.
