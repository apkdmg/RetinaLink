Your iMac.
A second display.

Install Host on your main Mac and Viewer on your iMac once. Approve your Mac, then let your display reconnect automatically.

One-time installation

Two Macs. One quick introduction.

  1. On your main Mac, open the Host DMG, drag RetinaLink Host onto Applications, then open Host from Applications.
  2. On your iMac, open the Viewer DMG, drag RetinaLink Viewer onto Applications, then open Viewer. You can also use Save Viewer Installer… in Host and copy that signed ZIP to your iMac.
  3. Choose Add Display in Host and select your iMac. If it is not listed, enter the iMac’s local hostname or IP address. Both Macs must be on a network that allows them to communicate.
  4. Compare the eight-digit verification number on both Macs. Choose Numbers Match — Pair on Host and Allow This Mac on the iMac only if both numbers match and you started setup. Cancel if they differ.
  5. Host explains the iMac’s FileVault restart limitation before pairing. Choose whether each app opens after sign-in. Encryption, automatic login and screen-lock settings are unchanged.
  6. Allow Screen Recording for Host and Local Network access for RetinaLink if macOS asks. Viewer does not need Screen Recording. Use Arrange Displays to position the extended desktop.

You can eject each DMG after copying its app. Install before pairing; do not run Viewer from the mounted installer. Host needs Apple silicon and macOS 13+. Viewer supports Intel macOS Catalina 10.15+ and Apple silicon macOS 11+. Wired Gigabit Ethernet is recommended for 5K. A private or company network can block discovery or direct connections; an IP address only bypasses discovery, not network isolation.

No Remote Login required

Your display connects through RetinaLink.

Normal installation, approval, streaming and reconnection use an encrypted app connection. You do not need to enable Remote Login, Remote Management or Screen Sharing. RetinaLink does not ask for an iMac account password during this standard flow.

Device trust is saved in each Mac’s login Keychain. Only the approved Host can use the display. A network advertisement alone cannot approve a Host or replace an existing pairing.

Viewer is discoverable for new setup for ten minutes after opening while unpaired. Choose Display → Make Discoverable for Setup on the iMac to start another setup window. Once paired, Viewer no longer accepts new pairing requests.

Already paired? Keep your pairing.

Update both apps in their existing permanent Applications locations. The new apps reuse the saved device credential and Host identity, then reconnect directly. There is no new verification step for an existing pair. Keep a single copy of each app.

RetinaLink does not switch off Remote Login automatically: it may be used by your administrator or other software. After confirming a direct RetinaLink connection, you may turn it off yourself if nothing else needs it.

Host can control signed Viewer updates through the app connection. Public update hosting is not configured in this test release; until it is available, install supplied signed releases in the same app locations.

Ready after sign-in

Viewer opens fullscreen after sign-in, reconnects to your trusted Mac and shows a quiet waiting screen when Host is unavailable. There is no daily code or Connect button on the iMac.

FileVault is never changed. On an Intel iMac with FileVault enabled, someone must unlock the startup disk locally after a restart before Viewer can run. This app cannot bypass that protection.

The optional Dedicated Display Setup for retired Catalina/Big Sur iMacs is an advanced account-management operation. Its existing Host administrator workflow still uses SSH and explicit administrator authorization. It is separate from normal pairing and streaming. Existing dedicated accounts remain unchanged by this update; normal setup does not create accounts, enable automatic login or alter locking.

Dedicated physical restart, first automatic sign-in and password-free wake validation remain pending. Native 5K at 60 updates/s remains a target; stable physical 60 fps across all workloads has not been established.
