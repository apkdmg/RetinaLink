RetinaLink

Your iMac.
A second display.

Install Host on your main Mac and Viewer on your iMac once. Approve your Mac, then let your display reconnect automatically.

One-time installation

Two Macs. One quick introduction.

  1. On your main Mac, open the Host PKG and follow Apple’s Installer, then open Host from Applications. If you have the Host DMG instead, drag RetinaLink Host onto Applications before opening it.
  2. On your iMac, open the Viewer DMG, drag RetinaLink Viewer onto Applications, then open Viewer. You can also use Save Viewer Installer… in Host and copy that signed ZIP to your iMac.
  3. Choose Add Display in Host and select your iMac. If it is not listed, enter the iMac’s local hostname or IP address. Both Macs must be on a network that allows them to communicate.
  4. Compare the eight-digit verification number on both Macs. Choose Numbers Match — Pair on Host and Allow This Mac on the iMac only if both numbers match and you started setup. Cancel if they differ.
  5. Host explains the iMac’s FileVault restart limitation before pairing. Choose whether each app opens after sign-in. Encryption, automatic login and screen-lock settings are unchanged.
  6. Allow Screen Recording for Host and Local Network access for RetinaLink if macOS asks. Viewer does not need Screen Recording. Use Arrange Displays to position the extended desktop.

You can eject each DMG after copying its app. Install before pairing; do not run Viewer from the mounted installer. Host needs Apple silicon and macOS 13+. Viewer supports Intel macOS Catalina 10.15+ and Apple silicon macOS 11+. Wired Gigabit Ethernet is recommended for 5K. A private or company network can block discovery or direct connections; an IP address only bypasses discovery, not network isolation.

No Remote Login required

Your display connects through RetinaLink.

Normal installation, approval, streaming and reconnection use an encrypted app connection. You do not need to enable Remote Login, Remote Management or Screen Sharing. RetinaLink does not ask for an iMac account password during this standard flow.

Device trust is saved in each Mac’s login Keychain. Only the approved Host can use the display. A network advertisement alone cannot approve a Host or replace an existing pairing.

Viewer is discoverable for new setup for ten minutes after opening while unpaired. Choose Display → Make Discoverable for Setup on the iMac to start another setup window. Once paired, Viewer no longer accepts new pairing requests.

Automatic USB

Connect your iMac directly.

With matching Host and Viewer @VERSION@ installed, connect a data-capable USB-C-to-USB-A cable directly from a rear USB-C port on the Apple silicon Mac Studio to a USB-A port on the Intel iMac. Leave both Macs’ existing company-network connections in place and keep Host and Viewer open. Do not use a USB hub, charging-only cable or USB-A-to-USB-A cable.

When macOS makes the USB connection available, RetinaLink finds your trusted Mac and selects USB automatically. You do not enter IP addresses, enable Remote Login or pair again. If USB disconnects, Viewer tries available network connections and stays fullscreen; when USB returns, it verifies the saved pairing before switching back. A switch can briefly interrupt the picture.

Pairing, FileVault and company network settings stay unchanged. RetinaLink uses the automatic local addresses supplied by macOS. It does not enable Internet Sharing or change network services, DNS, gateways or service order. Existing Local Network permission and company policies still apply.

The working cable tested with this Studio and Late-2014 iMac negotiated USB 2 high-speed (480 Mbps). USB 3 SuperSpeed operation and stable native 5K at 60 fps remain unvalidated. A cable’s advertised speed does not establish its actual negotiated speed or display performance.

Automatic Ethernet

Plug in a cable. Keep your pairing.

Connect a supported USB Ethernet hub to your main Mac, then connect an ordinary Ethernet cable from that hub to your iMac’s Ethernet port. Keep the main Mac’s existing company connection plugged in. Leave Host and Viewer open.

With the usual automatic macOS network settings, RetinaLink finds the connection without entering IP addresses. It uses the automatic local addresses macOS already provides. No router, DHCP server, administrator password or new pairing is required for that cable.

Your company network settings stay unchanged. RetinaLink does not assign static addresses or change DNS, gateways, DHCP, network service order or Internet Sharing. The iMac’s Ethernet port is occupied by the display cable; keeping its company access may require an existing Wi-Fi connection or another adapter.

Viewer prefers available Ethernet connections and verifies the saved pairing before switching a working display to a preferred route. Switching may briefly interrupt the picture. If the connection disappears, Viewer keeps trying the remaining routes and shows its waiting screen when none is available.

Ethernet status describes the network connection, not proof that it bypasses a switch. Adapter compatibility, disabled network protocols or company policies can prevent automatic discovery; RetinaLink leaves those settings unchanged. Testing with the physical UGREEN CM888 cable setup and real unplug/replug recovery remains pending. A cable does not guarantee stable 5K at 60 fps.

Already paired? Keep your pairing.

Update both apps in their existing permanent Applications locations. The new apps reuse the saved device credential and Host identity, then reconnect directly. There is no new verification step for an existing pair. Keep a single copy of each app.

RetinaLink does not switch off Remote Login automatically: it may be used by your administrator or other software. After confirming a direct RetinaLink connection, you may turn it off yourself if nothing else needs it.

Host controls signed updates for both Macs. With version 0.8.3 or later on both ends, only Host needs internet: Viewer receives and verifies its update through the existing paired display connection. Viewer 0.8.2 or earlier needs one upgrade first, using its own internet connection or a signed replacement in its existing location and account. Version 0.8.1 and later use GitHub-hosted signed update feeds. Releases through 0.8.0 need one normal signed replacement in each app’s original location to acquire those feed addresses. The replacement keeps the saved pairing.

Ready after sign-in

Viewer opens fullscreen after sign-in, reconnects to your trusted Mac and shows a quiet waiting screen when Host is unavailable. There is no daily code or Connect button on the iMac.

FileVault is never changed. On an Intel iMac with FileVault enabled, someone must unlock the startup disk locally after a restart before Viewer can run. This app cannot bypass that protection.

The optional Dedicated Display Setup for retired Catalina/Big Sur iMacs is an advanced account-management operation. Its existing Host administrator workflow still uses SSH and explicit administrator authorization. It is separate from normal pairing and streaming. Existing dedicated accounts remain unchanged by this update; normal setup does not create accounts, enable automatic login or alter locking.

Automatic-login reboot, fullscreen startup, reconnection and sleep/wake recovery have been tested on the dedicated Big Sur iMac. Other Macs and company policies can differ. Native 5K at 60 updates/s remains a target; stable physical 60 fps across all workloads has not been established.
