A second display.

Install Host on your main Mac. Host includes Viewer and guides you through installing it on your iMac.

Start on your main Mac

Drag. Open. Add your display.

  1. Drag RetinaLink Host onto the Applications folder in the installer window.
  2. Open RetinaLink Host from Applications, then choose Add Display. You can eject the installer after copying.
  3. On a new iMac, sign in and enable Remote Login under System Preferences → Sharing. Choose Only these users and allow the account you will use for setup. On newer macOS, Sharing is under System Settings → General.
  4. Back on Host, select your iMac and enter its account name. Verify the Mac’s identity and enter its password in the secure authentication dialog when asked. Host installs Viewer and saves the pairing.
  5. Allow Screen Recording for Host when macOS asks. Viewer does not require Screen Recording. Use Arrange Displays to place your new display.

Host requires an Apple silicon Mac with macOS 13 or later. Viewer supports Intel macOS Catalina 10.15 or later and Apple silicon macOS 11 or later. Keep both Macs on a trusted network; wired Gigabit Ethernet is recommended for 5K.

Know before you connect

Why does RetinaLink need Remote Login?

This version uses Apple’s encrypted SSH service to install Viewer, manage it and carry the display connection. Remote Login must remain enabled on the iMac while you use RetinaLink. It is not just a one-time installation requirement. Host does not need Remote Login enabled.

Remote Login is a general macOS remote-access service. People with an allowed account’s valid credentials may be able to sign in remotely. RetinaLink’s saved streaming key is restricted to its display tunnel and cannot open a shell, but enabling the service is still a decision you should be comfortable with.

Choose Only these users rather than allowing every account. Full disk access for remote users is not required. Do not expose Remote Login through your router. On a company Mac, check with your IT team.

If you prefer to leave Remote Login off, this release cannot provide Host-managed setup or its automatic display connection. A connection without SSH would require a future Viewer connection service; it is not included in this installer.

Apple’s Remote Login instructions. Turning Remote Login off disconnects this version of RetinaLink. Turning it back on normally allows the saved pairing to reconnect.

Ready whenever you sign in

Enable Viewer startup during setup. Viewer opens fullscreen after sign-in, reconnects to your trusted Mac and shows a quiet waiting screen when the Host is unavailable. There is no daily pairing code or Connect button on the iMac.

FileVault is never changed. With FileVault enabled on an Intel iMac, someone must unlock its disk locally after a restart before Viewer can run.

For a retired Intel iMac running Catalina or Big Sur with FileVault already off, the optional Dedicated Display Setup creates a separate non-administrator account and configures automatic login. Anyone with physical access can use that account; keep personal files out of it. Your administrator must approve this option. Setup does not create partitions or install another copy of macOS.

Dedicated account provisioning and off/on recovery have passed on the test iMac. Physical restart, first automatic sign-in and password-free wake verification remain pending. Native 5K at 60 updates per second is a target; stable physical 60 fps across all workloads has not been established.

Already using RetinaLink?

Keep Host in its existing permanent Applications location and use its update controls where available. Pairing is retained between compatible releases signed by the same developer. If you already installed it in your home Applications folder, avoid keeping a second copy in the system Applications folder.

Host handles Viewer updates. Public automatic-update hosting is not configured in this test release.
